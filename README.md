# Mega Parrillada Argentina

Sitio web oficial de **Mega Parrillada Argentina**, restaurante de comida argentina ubicado en C.C. Plaza Atanasio Tzul, Local 20, Guatemala.

## Estructura del proyecto

```
/
├── index.html            # Pagina principal
├── menu.html             # Pagina del menu completo
├── styles.css            # Estilos compartidos
├── favicon.png           # Favicon (Sol de Mayo)
├── favicon.ico           # Favicon formato ICO
├── apple-touch-icon.png  # Icono para dispositivos Apple
├── img/
│   ├── menu/             # Imagenes del menu (1-13.jpeg)
│   ├── logo-clean-dark.png
│   ├── logo-clean-light.png
│   ├── logo-oficial.png
│   └── ...               # Fotos de platos y parrilladas
└── README.md
```

## Secciones

- **Hero** - Presentacion principal con CTA
- **Strip** - Carnes importadas, asado al carbon, porciones mega
- **Especialidades** - Grid de 8 platos destacados
- **Para compartir** - Parrilladas familiares
- **Por que elegirnos** - 4 razones principales
- **Menu CTA** - Llamado a accion para ver el menu
- **Salmo 91** - Mensaje inspiracional
- **Ubicacion y horarios** - Mapa e informacion de contacto
- **Menu** - 13 paginas del menu en scroll vertical

## Tecnologias

- HTML5, CSS3 (sin frameworks)
- Google Fonts (Anton, Mulish, Playfair Display)
- Responsive design (mobile-first breakpoints)
- Lazy loading de imagenes
- Scroll reveal animations
